
# Proyecto Final - Parte 2: Aplicación React

## Descripción del Proyecto
Este proyecto es una aplicación Front End desarrollada de forma paulatina para profundizar en las características de React, utilizando Vite como herramienta de construcción y Vercel para el despliegue continuo.

## Acuerdos de la Forma de Trabajo (Git Flow Simplificado)
Para mantener el repositorio limpio y fácil de escalar, el equipo seguirá las siguientes reglas:
1. **Rama Principal (`main`):** Solo contendrá código de producción 100% estable.
2. **Ramas de Trabajo (`feature/`):** Cada nueva funcionalidad o avance se desarrollará en una rama independiente (ej. `feature/estructura-inicial`).
3. **Integración:** Todo cambio deberá integrarse mediante un **Pull Request (PR)** en GitHub, requiriendo la revisión de al menos un compañero antes de fusionarse.
